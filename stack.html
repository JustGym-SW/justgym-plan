Zapier

Zapier Skills

Two Zapier skills are configured — one per automation. These are saved in Zapier and can be triggered from the Copilot interface.

Hourly Email Triage & Auto-Reply

Trigger: every hour
Fetches unread emails, checks for sleeper members, searches the Knowledge Base, and sends an auto-reply or WhatsApp escalation. Logs every email. Marks all processed emails as read.

Apps: Gmail • Google Sheets • WhatsApp Business

B2B Staff Benefits Outreach

Trigger: daily at 9:00 AM
Finds local businesses via SerpAPI, looks up emails via Hunter, checks the log for recent contact, has Claude draft a pitch, sends from the outreach inbox, and logs every attempt.

Apps: SerpAPI • Hunter • Claude • Gmail • Google Sheets

Authentication

How Each Tool Connects

Most tools connect via Zapier's Connected Accounts. API keys are entered once and stored securely in Zapier.

  • Gmail

    Google OAuth via Zapier

    In Zapier, go to Connected Accounts and add each Gmail address separately. Zapier uses Google's OAuth flow — you log in with Google and grant Zapier access. No password is stored. Repeat for both the support and outreach inboxes.

  • Sheets

    Google OAuth via Zapier (same account)

    If you have already connected a Gmail account to Zapier, Google Sheets uses the same connection automatically. No separate login required.

  • WhatsApp

    WhatsApp Business login

    Connect WhatsApp Business via the WhatsApp Business app or API. In Zapier, add the WhatsApp Business connection and follow the authentication flow. Requires a WhatsApp Business account with an active phone number.

  • Claude

    Anthropic API key

    Go to console.anthropic.com and create an API key under your Anthropic account. In Zapier, add the Anthropic (Claude) connection and paste the key. This ties to your Anthropic account — it is not a separate login, just the key from your existing account.

    console.anthropic.com
  • SerpAPI

    Direct API key (called from Zapier webhook step)

    Sign up at serpapi.com and copy your API key from the dashboard. SerpAPI is not available as a native Zapier app, so it is called via a Zapier Webhooks step with the key passed as a query parameter. The free tier gives 100 searches per month.

    serpapi.com
  • Hunter

    Hunter.io API key or OAuth

    Sign up at hunter.io and connect via Zapier's Hunter integration. You can use OAuth or paste an API key from your Hunter dashboard. The free tier provides 25 searches per month, which covers small daily volumes.

    hunter.io
